بنية تعدد الشروحات — الشاطبية التفاعلية الكاملة
==============================================

المشروع مهيّأ لاستقبال شروحات إضافية (مثل: سراج القارئ لابن القاصح، أو إبراز المعاني لأبي شامة، أو فتح الوصيد للسخاوي) دون تعديل كود الواجهة:

1. أنشئ ملف JSON داخل هذا المجلد (data/commentaries/) مثلاً: siraj.json
   بالصيغة التالية:
   {
     "id": "siraj",
     "title": "سراج القارئ المبتدئ",
     "author": "ابن القاصح العذري",
     "sections": [
       { "from": 1, "to": 4, "summary": "خلاصة...", "full": "نص الشرح الكامل..." },
       { "from": 5, "to": 9, "summary": "خلاصة...", "full": "نص الشرح الكامل..." }
     ]
   }

2. أضف تعريف الشرح في ملف data/commentaries/index.json:
   {
     "id": "siraj",
     "title": "سراج القارئ المبتدئ",
     "author": "ابن القاصح العذري",
     "builtin": false,
     "file": "data/commentaries/siraj.json"
   }

وسيظهر تلقائياً زر تبديل بين «الوافي» و«سراج القارئ» داخل نافذة شرح كل بيت!
